## embyEverywhere

> **Adds Emby jump links on many websites.**

![](https://github.com/kjtsune/embyToLocalPlayer/raw/main/embyEverywhere/embyEverywhere.webp)

> **Installation**: install a userscript extension in your browser, then refresh the page and click the script link below.

> Extension links:
[Tampermonkey](https://chromewebstore.google.com/detail/lcmhijbkigalmkeommnijlpobloojgfn) |
[Violentmonkey](https://chrome.google.com/webstore/detail/violent-monkey/jinjaccalgkegednnccohejagnlnfdag) |
[Tampermonkey v3 (not recommended, requires enabling developer mode)](https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo)

> Script link: [embyEverywhere.user.js](https://github.com/kjtsune/embyToLocalPlayer/raw/main/embyEverywhere/embyEverywhere.user.js)

> **Configuration: userscript extension -> this script -> Edit (edit the content above according to the comments) -> Save -> refresh the corresponding page.**

**Search**

* bgm.tv: searches by title and premiere date.
* Douban: searches by imdb id.
* imdb: searches by imdb id.
* tmdb: searches by tmdb id.
* tvdb: searches by tvdb / imdb id.
* trakt: searches by imdb id.
* google: searches using the imdb id, or the title and year, from the movie/TV card in the search results.

**FAQ**

* If the page doesn't have the info needed for the search above, e.g. imdb id, it exits without searching.
* If you run into issues, try clearing the userscript storage yourself first.
